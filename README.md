# 대학교 부수기 🚀

실제 대학교 캠퍼스 정문에서 로켓을 발사해 건물에 들이박는 모바일 3D 웹 게임. **대학교 선택하기**를 누르면 가나다순으로 각 학교의 대표 건물이 나오고, 좌우로 넘겨 고르면 그 건물에 로켓을 쏜 뒤 게임이 시작됩니다.

- **경희대학교 국제캠퍼스** (선택 화면에서는 '경희대 국제')
- **중앙대학교 서울캠퍼스**: 영신관(막돌 고딕 건물), 100주년기념관, 중앙도서관 시계탑, 청룡상 등 직접 모델링, 흑석동 언덕 지형
- **성균관대학교 인문사회과학캠퍼스**: 돌기둥 정문, 명륜당·대성전·비천당 한옥, 600주년기념관, 호암관 천문대 등 직접 모델링, 북악산 자락 지형 (지도에 없는 명륜동 주택은 자동 생성)
- **고려대학교 서울캠퍼스**: 화강암 고딕 본관과 중앙 탑, 중앙광장, 대학원 도서관, 파이빌99 등
- **연세대학교 신촌캠퍼스**: 담쟁이 덮인 언더우드관, 중앙도서관, 백주년기념관 등
- **서울대학교 관악캠퍼스**: 정문 샤 조형물, 규장각, 중앙도서관, 미술관 등과 관악산 지형
- **한양대, 서강대, 한국외대, 서울시립대, 건국대, 동국대, 홍익대 서울캠퍼스**: 실제 지도·지형과 학교별 건물 색, 본관·홍문관 등 대표 건물
- **국민대학교**: 16층 북악관, 성곡도서관, 북악산 자락 지형 (지도에 없는 정릉동 주택은 자동 생성)
- **숭실대학교**: 아치 지붕 정문, 형남공학관, 안익태기념관
- **세종대학교**: 한옥 정문, 아사달 연못 앞 박물관, 대양AI센터
- **단국대학교 죽전캠퍼스**: 돔을 얹은 범정관과 분수 광장, 법화산 자락 지형
- **분캠퍼스**: 경희대 서울(평화의전당 쌍탑, 본관 열주), 성균관대 수원(타원형 삼성학술정보관), 고려대 세종, 연세대 송도(언더우드 기념도서관)·원주, 서울대 연건(시계탑 대한의원), 한양대 ERICA, 한국외대 용인(팔각탑 학생회관, 드럼형 도서관), 건국대 충주, 홍익대 세종, 단국대 천안

## 조작
- **왼쪽 화면 드래그**: 조이스틱으로 로켓 조종 (상하 반전 버튼 있음)
- **오른쪽 화면 누르기**: 스킬 버튼
  - 🚀 기본 로켓: 부스트 (게이지 소모, 자동 충전)
  - 🎯 탄도미사일 (300조각 파괴 시 해금, 위쪽 바에서 선택): 뒷단을 분리하고 누른 순간의 방향으로 돌진. 조종은 안 되지만 속도가 끝없이 커지고, 폭발 반경은 충돌 순간 속도(km/h)의 1/23 m
  - 💣 폭격 로켓 (1200조각 파괴 시 해금): 기본 로켓과 같은 성능, 플레어처럼 폭탄 18발을 좌우로 뿌림 (6발은 바로, 6발은 1초, 6발은 2초 뒤 폭발하며 그동안 튕기고 굴러감, 반경 14.3m, 3회 충전, 약 1.5초마다 1회 회복)
  - 💥 집속탄 (3400조각 파괴 시 해금): 소형 미사일 18발로 분열. 속도는 그대로, 날아간 시간만큼 폭발 반경이 커짐 (10m→30m)
  - ☢️ 핵폭탄 (7000조각): 충돌하거나 스킬(기폭)을 누르면 반경 62m 핵폭발, 섬광·충격파·버섯구름
  - 🛰️ 공중 지원 (12000조각): 부딪힌 곳에 하늘에서 레이저 빔이 내려와 반경 25m 안의 모든 층을 소멸
  - ⚫ 블랙홀 미사일 (20000조각): 충돌하거나 스킬(전개)을 누르면 블랙홀이 생겨 삼킨 조각만큼 계속 커지고(반경 22m→최대 170m), 먹을 게 있는 동안 계속 살아남음(최대 16초). 화면 전체 중력 렌즈(빛 휘어짐)·광자 고리, 케플러 회전 강착원반, 조석력으로 늘어나는 파편, 어두워지는 세상과 낮은 웅웅거림
  - 🌋 지진탄 (30000조각): 스킬(드릴)을 누르면 점점 빨라지며 수직으로 땅에 꽂히고, 기본 반경 100m(드릴로 떨어지면 떨어진 높이의 0.25배) 지진파가 건물 1~2층을 무너뜨려 위층까지 통째로 주저앉힘
  - 🔴 레이저 미사일 (45000조각): 스킬을 누르고 있는 동안 진행 방향으로 미사일 반지름 4배 굵기의 레이저(사거리 840m, 파괴 반경은 빔 반지름의 2.2배)를 쏴서 닿는 건물을 잘라냄 (약 6초 사용, 약 4.6초에 완충)
  - 🧨 유도 폭격 로켓 (60000조각): 로켓은 65km/h로 날고, 스킬마다 탄두 미사일 12발(0.04초 간격, 연타하면 이어서 계속 발사, 최대 4회 저장, 0.9초마다 1회 충전). 탄두 절반은 50m, 절반은 100m까지 같은 시간에 떠오른 뒤 진행 방향 90° 안, 50m 이상 떨어진 무작위 건물로 점점 가속하며 돌진(최고 1000m/s, 12발 중 1발은 최고 190m/s, 폭발 반경은 충돌 속도(km/h)의 1/110 m). 범위에 건물이 없으면 70m/140m 위로 올라가 남은 건물로 돌진
- PC: 방향키/WASD 조종, Space 스킬, Esc 설정
- **⚙️ 설정**: 그림자, 밤 모드(별이 뜬 달밤 하늘, 불 켜진 창문), 소리, 상하 반전, 캠퍼스 복구 (설정 창이 열려 있는 동안 게임 일시정지)

## 특징
- OpenStreetMap 실제 건물 외곽선과 실제 지형 고도로 만든 캠퍼스와 주변 (경희대 553채, 중앙대 614채)
- 주요 캠퍼스 건물은 사진을 참고해 직접 모델링 (`src/models-cau.js`는 중앙대). 경희대: 정문(개선문과 열주), 중앙도서관·체육대학관 열주, 예술디자인대학 고딕 탑, 선승관 벽돌 원형 경기장, 노천극장, 천문대 돔 등 (`src/models.js`)
- 창문·유리·벽돌·아치는 셰이더로 그림 (`src/facade.js`), 지형은 도로·운동장·건물 자리를 평평하게 다듬고 숲에는 가을 단풍
- 모든 건물(기둥·탑·지붕 포함)은 시작할 때 미리 격자 조각(층 × 2~5m 블록, 약 12만 개)으로 나눠 둠
- 로켓이 박힌 부위 주변 조각만 떨어져 나가고, 받칠 것이 없어진 위쪽 조각과 지붕 보는 무너져 내림
- 충돌 후 정문에서 새 로켓이 자동으로 다시 발사

## 실행
빌드 과정 없는 정적 사이트입니다 (three.js는 CDN에서 불러옴).

```bash
python3 tools/serve.py 8792   # http://localhost:8792
```

## 데이터 다시 만들기
`tools/build_data.py`가 OSM 데이터와 Copernicus GLO-30 표고(건물·나무 높이를 걸러 낸 지면)를 학교별 파일로 굽습니다.

```bash
python3 tools/build_data.py cau osm_all.json dem_cache data/cau.json
```

학교를 추가하려면 `tools/build_data.py`의 `CAMPUSES`와 `src/campuses.js`에 항목을 넣으면 됩니다. 지도에 없는 주택을 채울 때는 `infill`에 `regions`(채울 구역 목록), `avoid`(피할 구역 종류), `tallGap`(고층 건물과 띄울 거리)을 지정할 수 있습니다.
